# DocuFlow AP v1.0.0 — Draft Release Notes

> Draft for the portfolio release. Do not publish or tag until the final acceptance checklist is complete.

## Overview

DocuFlow AP is a production-style accounts-payable document-automation portfolio system.

The release demonstrates a controlled path from unstructured invoice intake to OCR, canonical extraction, deterministic validation, duplicate and purchase-order matching, human review, accounting export, downstream delivery, and full operational visibility.

All included data and evidence are synthetic or sanitized.

## Highlights

- Local PDF/image invoice intake with content-based file validation
- Source preservation in S3-compatible MinIO storage
- Asynchronous preprocessing and Tesseract OCR
- Canonical header and line-item extraction with evidence
- Deterministic validation and versioned decision policy
- Business duplicate, vendor identity, and purchase-order matching
- Real Supabase authentication and database-authoritative RBAC
- Human review ownership, notes, corrections, reruns, and resolution
- Idempotent JSON/CSV accounting exports
- HMAC-signed webhook and email delivery with retry history
- Interactive Next.js operations dashboard
- Repeatable Docker and local-Supabase setup
- Executable acceptance and smoke validation

## Application roles

- `AP_CLERK`
- `REVIEWER`
- `ADMIN`

Role capabilities remain enforced by FastAPI and PostgreSQL even when the action originates from the browser dashboard.

## Decision outcomes

- `AUTO_APPROVED`
- `REVIEW_REQUIRED`
- `REJECTED`

Straight-through approval requires all configured deterministic controls. Confirmed duplicates are rejected. Missing or uncertain approval evidence moves to review.

## Export formats

- JSON
- CSV

Equivalent requests for the same document source version and format reuse the existing export.

## Delivery channels

- HMAC-signed HTTP webhook
- deterministic local email sink
- SMTP email adapter

Retryable network/provider failures use capped retry behavior and preserve every attempt.

## Known limitations

This release is portfolio evidence, not a deployed accounting platform.

It does not include:

- live ERP posting;
- payment execution;
- organization-specific tax/accounting policy;
- malware scanning;
- managed production secrets;
- hosted observability and alerting;
- production backup and disaster recovery;
- real vendor or invoice data;
- legal/compliance approval for financial production use.
