# DocuFlow AP

Intelligent invoice OCR, validation, purchase-order matching, and human-review system.

## Project status

Week 1 — Foundation

## Portfolio disclosure

DocuFlow AP is an independent simulated-client portfolio project built using synthetic data.

## Approved MVP flow

1. Secure invoice intake
2. File validation and source preservation
3. Image preprocessing
4. Local OCR
5. Structured extraction with confidence and evidence
6. Deterministic validation
7. Duplicate and purchase-order matching
8. Human review or straight-through approval
9. CSV, XLSX, and JSON export
10. Complete audit history

## Main technologies

- Python and FastAPI
- Celery and Redis
- OpenCV and Pillow
- Tesseract OCR
- Next.js and TypeScript
- Supabase PostgreSQL, Auth, and Storage
- Docker Compose

## Data policy

Development, testing, screenshots, and demonstrations must use synthetic or sanitized data only.
